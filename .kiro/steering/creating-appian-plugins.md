# Creating Appian Plug-ins

Use this guidance when building, scaffolding, or setting up the build for an Appian plug-in:
smart services, expression functions, connected systems, integrations, custom data types,
servlets, or SAIL component plug-ins. Covers appian-plugin.xml descriptors, the Appian Plug-in
SDK, Gradle setup, and META-INF/lib packaging.
